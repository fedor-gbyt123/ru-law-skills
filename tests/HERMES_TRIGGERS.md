# Проверка в Hermes Agent (2026-11-21)

Проверял Claude Sonnet 5.5 прямым запуском Hermes: `hermes -z "<вопрос>" --provider deepseek -m deepseek-v4-pro` (Hermes Agent v0.23.2, модель DeepSeek V4 Pro). Скиллы скопированы в `%LOCALAPPDATA%\hermes\skills` (идентичны репозиторию, `hermes skills list`: source local, enabled). Какие скиллы Hermes открыл, определялось по записи сессии (`hermes sessions export`, вызовы `skill_view`), а не по тексту ответа. Каждый вопрос — в новой сессии, по одному запуску.

- **Режим A (без строки-триггера):** рабочая папка без `AGENTS.md`.
- **Режим B (со строкой):** рабочая папка с `AGENTS.md`, где лежит строка-триггер из `INSTALL.md`. В глобальные настройки Hermes строка не вставлялась.
- Режим A: первый вопрос каждого скилла (11). Режим B: все 33 вопроса из `tests/TRIGGERS.md`.

## Итог

| Режим | Прогонов | Нужный скилл открыт | Комментарий |
|---|---|---|---|
| A, без строки | 11 | 10 | Единственный промах — «Подрядчик прислал договор…»: договора в сообщении нет, Hermes попросил его прислать, не открывая скилл |
| B, со строкой | 33 | 32 | В вопросе №3 («Собираюсь подписать оферту сервиса») открыт `ru-online-terms` вместо `ru-contract-review` — тоже уместный выбор. Во **всех 33** запусках первым открывался `ru-law`, затем профильный скилл |

Неверного по смыслу скилла не открыто ни разу. Стоимость всех 46 запусков около 0,68 $ (в среднем 0,015 $ на запрос).

## Содержательные задачи (режим B)

- **11.3** (Екатеринбург должен Новосибирску): ✅ «Стороны: истец — вы (Новосибирск), ответчик — фирма-должник (Екатеринбург)»; Арбитражный суд Свердловской области по месту ответчика (ст. 35 АПК); Новосибирская область упомянута только как пример договорной подсудности; пошлина 27 500 ₽.
- **4.2** (утечка базы, 2000 записей): ✅ сроки 24 и 72 часа; ч. 12 ст. 13.11 КоАП (3–5 млн ₽ для юрлиц) за утечку и отдельно ч. 11 (1–3 млн ₽) за неуведомление.

## Оговорки

- По одному запуску на вопрос; срабатывание вероятностное, цифры ориентировочные.
- Hermes сам активно ищет подходящий скилл по списку в системном промпте, поэтому разница между режимами небольшая. Строка-триггер делает поведение единообразным: `ru-law` открывается всегда первым.
- Это одна модель (DeepSeek V4 Pro). На другой модели результат может отличаться.
