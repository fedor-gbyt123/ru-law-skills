# Установка и включение ru-law-skills

## Главное: как сделать, чтобы ИИ открывал скиллы

Скилл включается, когда модель сама решает его открыть. На короткие бытовые вопросы она нередко отвечает по памяти, а это ровно то, от чего скиллы защищают: выдуманные суммы штрафов, устаревшие пошлины, лишние статьи. Надёжнее всего добавить в инструкции одну строку (**строка-триггер**):

> Если вопрос касается права РФ (договоры, штрафы, суды, увольнения, персональные данные, реклама, авторские права, товарные знаки, претензии, иски), перед ответом вызови скилл `ru-law` и работай по нему. Суммы штрафов, пошлины и сроки не называй по памяти.

Куда её вставить, зависит от программы (см. ниже). Это одна и та же строка везде.

## Claude Code

```bash
/plugin marketplace add <путь к папке или адрес репозитория>
/plugin install ru-law@ru-law-skills
```

Перезапустите Claude Code. Затем:

- **Хук уже входит в плагин** (`hooks/`): когда в вопросе есть юридические слова («договор», «штраф», «уволить», «оферта» и т. п.), он подсказывает модели вызвать `ru-law`. Нужен Python 3. Хук работает только в Claude Code.
- Для надёжности добавьте строку-триггер в `CLAUDE.md` (личный или проекта).

## Чат: claude.ai и приложение Claude

В чате **хуков нет**: ваш текст сразу уходит на сервер, и запустить на вашем компьютере скрипт плагин не может. Там работает только то, что постоянно лежит в контексте модели:

1. Загрузите скиллы: каждая папка из `skills/` отдельным zip-архивом, папка должна лежать в архиве целиком (внутри `SKILL.md` и `references/`). В PowerShell: `Compress-Archive -Path skills\ru-law -DestinationPath ru-law.zip`. Загружайте **все 11**, иначе `ru-law` будет направлять в скиллы, которых нет. Раздел загрузки скиллов находится в настройках (название пункта может отличаться в вашей версии).
2. Создайте **проект** и вставьте строку-триггер в инструкции проекта (или в личные настройки). Задавайте юридические вопросы внутри этого проекта.

## Hermes Agent и другие агенты

1. Скопируйте папки из `skills/` в папку скиллов агента. Путь и формат подключения зависят от агента; для Hermes он записывается в разделе ниже после проверки.
2. Вставьте строку-триггер в `AGENTS.md` или системную инструкцию агента.

### Результат проверки в Hermes

Не проверено. Заполняется после прогона `tests/TRIGGERS.md` в самом Hermes: путь к папке скиллов, вставлена ли строка, сколько вопросов из набора вызвали скилл.

## Как проверить, что скилл включился

Задайте: «Хочу делать рассылку по базе старых клиентов, это законно?» В ответе со скиллом будут допущения в начале и пометка о дате сверки справочника. Если ответ общий, без допущений и без даты сверки, скилл не включился: проверьте, что вставлена строка-триггер.
