# Шаблон: согласие на получение рекламной рассылки

Согласие должно быть предварительным и конкретным; бремя доказывания согласия — на рекламораспространителе (38-ФЗ ст. 18 — см. `references/norms.md`). Храни запись о согласии: дату, время, источник (форма на сайте, подписной лист), версию текста, на который согласился адресат. Отписка должна работать без препятствий — рекламораспространитель обязан немедленно прекратить рассылку по требованию.

---

## Для формы на сайте / лендинге (текст под чекбоксом)

«[ ] Согласен(на) получать рекламные и информационные рассылки от [наименование, ИНН] на [телефон / e-mail] по каналам [SMS, e-mail, мессенджеры, звонки]. Согласие может быть отозвано в любой момент: письмом на [e-mail] или по ссылке отписки в каждом сообщении. [Ссылка на политику обработки персональных данных].»

Чекбокс — отдельной строкой, незаполненный по умолчанию, не совмещённый с кнопкой отправки формы и с согласием на обработку персональных данных.

## Для офлайн / подписного листа

«Я, [ФИО], даю согласие [наименование, ИНН, адрес] на направление мне рекламы по сетям электросвязи: [SMS на номер ___, звонки на номер ___, e-mail на ___]. Настоящее согласие действует [срок или «до отзыва»] и может быть отозвано мной в любой момент заявлением на [контакты]. [Дата] [Подпись]».

## Что проверить перед рассылкой

- Согласие получено до первой рассылки и его можно доказать (лог формы с датой/временем, подписной лист).
- Рассылка — не автоматический дозвон/авторассылка без участия человека (запрещено — ст. 18 38-ФЗ).
- В каждом сообщении — работающая ссылка отписки; отписанный адрес исключается из рассылки немедленно.
- Реклама по сетям электросвязи без согласия — штраф по КоАП РФ ст. 14.3 ч. 4.1 (см. `references/norms.md`).
- База для рассылки обрабатывается по 152-ФЗ — связь со скиллом `ru-personal-data`.
